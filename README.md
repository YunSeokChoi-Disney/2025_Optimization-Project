**Project 3: Reinforcement Learning in Grid Environments**

*Focus: Deep Q-Network (DQN) and Path Optimization

*Objective: To train an agent to find the optimal path in a maze (MiniGrid environment) using Deep Reinforcement Learning (DRL).

*Key Methodology:

-Algorithm: Implemented the DQN (Deep Q-Network) algorithm, combining Q-Learning with Deep Neural Networks (CNN) to process image-based state inputs.

-Key Features: Utilized Replay Buffer to remove correlations between experiences and Target Network to ensure stable learning.

-Reward Design: Developed a reward system that incentivizes reaching the goal quickly while penalizing unnecessary movements.

*Result: Analyzed the agent's learning curve (reward/episode) and visualized how the epsilon-greedy policy transitions from exploration to exploitation to achieve the shortest path.
