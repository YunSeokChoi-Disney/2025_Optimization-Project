# Project 1 — Numerical Optimization Algorithms

**Course:** Introduction to Optimization (최적화개론), Hanyang University
**Focus:** Basic optimization theory and algorithm development

> Implement fundamental numerical optimization algorithms **from scratch**, without relying on
> pre-built optimization libraries.

---

## Objective

Build the core mathematical logic of classic optimization algorithms in Python and verify the
**convergence** and **optimality** of the solutions they produce.

## Key Tasks

- **Unconstrained optimization** — implemented iterative solvers such as **Gradient Descent** and
  **Newton's Method**.
- **Linear Programming (LP)** — solved LP problems using the **Simplex method** (or a comparable
  numerical approach).
- **Quadratic Programming (QP)** — minimized quadratic cost functions subject to linear constraints.

## Technical Implementation

Each algorithm's mathematical logic was constructed in Python from first principles, and the
resulting iterates were checked for convergence toward the optimal solution.
